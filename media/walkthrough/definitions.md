# Go to Definition

Codea Air Code can set up the **Lua extension** by sumneko for your linked projects. With it, Go to Definition (F12), Find All References and hover work across your tabs, the folders inside your projects, your linked dependencies and Codea's API.

Auto-completion and signature help still come from Codea, as before.

A name defined in several linked projects, such as a class both have, lists each of them.
