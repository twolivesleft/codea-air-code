# Creating a project

Click the **New Project** button, the Codea logo with a plus, at the top of the Explorer or of the Projects section, and enter a name.

From the right-click menu of a folder in the Explorer, the project goes in the collection that folder stands for:

| Folder | Collection in Codea |
|---|---|
| The workspace folder | Documents |
| `iPad Projects` | iPad Projects, created if needed |
| `iPad Projects/Game.codea` | iPad Projects, beside Game |

The project is created in Codea from your default template, then copied into your folder and linked.

Renaming a project's folder renames the project in Codea, and **Delete Project in Codea** in the same menu deletes it there, after asking. Deleting the folder alone never deletes the project in Codea.
